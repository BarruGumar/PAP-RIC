# Biblioteca de músicas do RIC (offline)

Coloca aqui ficheiros de áudio **já descarregados**. O RIC **não** usa internet para tocar músicas.

## Géneros (pastas)

| Pasta | Género |
|---|---|
| `pop/` | Pop |
| `rock/` | Rock |
| `hiphop/` | Hip-Hop |
| `eletronica/` | Eletrónica |
| `jazz/` | Jazz |
| `blues/` | Blues |
| `classica/` | Clássica |
| `folk/` | Folk |
| `country/` | Country |
| `reggae/` | Reggae |
| `metal/` | Metal |
| `rb_soul/` | R&B / Soul |
| `latina/` | Latina |
| `fado/` | Fado |
| `relaxamento/` | Relaxamento |
| `infantil/` | Infantil |
| `gospel/` | Gospel |
| `soundtrack/` | Bandas sonoras |

Podes criar pastas novas se precisares de outro género.

## Exemplo

```text
ric/musica/
  pop/
    minha_musica.mp3
  fado/
    tema.mp3
  classica/
    piano_simples.wav   ← demo de teste
```

- **Género** = nome da pasta  
- **Música** = ficheiro (`.mp3`, `.wav`, `.ogg`, `.m4a`, `.flac`, `.aac`)

## Controlo

- “Toca …” — começa a música
- “Pausa” — para e guarda a posição
- “Continua” / “Retoma” — volta do mesmo ponto
- Também há botões **Pausar** / **Continuar** no painel

## Na conversa

- “Que géneros há?”
- “Que músicas tens de jazz?”
- “Toca uma de relaxamento”
- “Pausa”
- “Continua”
